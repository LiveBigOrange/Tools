XML JSON 互转常见问题

XML 元素的属性会以 @ 前缀表示，例如 <item id="1"> 会转换为 {"@id":"1"}。

相同标签名的子元素会自动合并为数组，例如多个 <item> 会转换为 "item": [...]。

可以处理较大的文本内容，但建议单次处理不超过 10MB，以保证浏览器性能。
