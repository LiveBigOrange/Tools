摩斯密码常见问题

标准摩斯电码仅支持英文字母和数字。本工具通过将中文字符转换为Unicode十六进制编码后再进行摩斯电码编码，从而实现对中文的支持。

点击「播放」按钮，工具会使用 Web Audio API 生成对应的短音（点）和长音（划），模拟传统摩斯电码的听觉效果。
