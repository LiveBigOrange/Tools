# AGENTS.md

## Project Overview

Static front-end tool site (tools.yzn123.cc) — 129+ online tools, zero backend, zero build step. All HTML/CSS/JS, no framework, no package manager, no bundler.

## Critical Constraints

- **Must work on `file://` protocol** (local preview by double-clicking index.html). Never use absolute paths (`/assets/...`) — always relative (`../assets/...` from tools/, `assets/...` from root). Note: `fetch()` for `search-index.json` will be blocked by CORS on `file://`, so homepage and about page content won't load locally without a server.
- **Brand name is `在线工具`** (not "IT工具箱"). Used in SEO tags, footer, and structured data.
- **No comments in code** unless explicitly requested.

## Architecture

- `index.html` — Homepage with inline `<style>` and `<script>`. NOT linked to global.css for homepage-specific styles. Fetches `search-index.json` to load tool data (no hardcoded fallback).
- `tools/tool-template.html` — Mustache-style template (`{{TOOL_NAME}}`, etc.). Used by `generate-tools.js` to stamp out tool pages. Do not edit generated tool HTML directly — edit the template and regenerate.
- `search-index.json` — Single source of truth for tool metadata (name, aliases, description, category, path, keywords). Both the homepage and build scripts read this.
- `assets/css/global.css` — Shared styles for header, footer, tool pages, 404, about. Homepage overrides these with inline styles.
- `assets/js/libs.js` — CDN lib loader (`loadLibs('crypto', 'qrcode')`). Lazy-loads third-party scripts on demand. Add new CDN entries to `CDN_LIBS` object.
- `assets/js/theme.js` — Multi-theme system (blue/purple/green/orange/pink), persisted via localStorage `themeIndex`.
- `assets/js/record-tool.js` — Tracks tool usage history in localStorage (`tool_history`, max 30 entries). Tool pages set `window.TOOL_INFO` before loading this script.

## PWA

- `manifest.json` — Web App Manifest declaring app name, icons (72-512px in `assets/icons/`), theme color, display mode (standalone), start URL.
- `sw.js` — Service Worker with network-first for HTML pages (updates visible immediately) and cache-first for static assets (CSS/JS/images). Skips registration on `file://` protocol. Cache versioned as `toolbox-pwa-v1`; bump `CACHE_NAME` to force cache refresh.
- Every page includes `<link rel="manifest">`, `<meta name="theme-color">`, `<link rel="apple-touch-icon">`, and SW registration script.
- Tool template already includes PWA support; new tools generated via `generate-tools.js` will inherit it automatically.

## Build Scripts (run with Node.js)

```bash
node generate-tools.js    # Regenerates all tool pages from template + search-index.json
node generate-sitemap.js  # Regenerates sitemap.xml from search-index.json
```

Always run both after modifying `search-index.json` or `tools/tool-template.html`.

## Adding a New Tool

1. Add entry to `search-index.json` (with name, aliases, description, category, path, keywords)
2. Add category color class in `index.html` inline `<style>` (`.cat-xxx { --cat-color:...; --cat-bg:...; --cat-border:...; }`) if new category
3. Add category to `categoryMeta` object in `index.html` `<script>` (icon + cls)
4. Run `node generate-tools.js`
5. Run `node generate-sitemap.js`
6. Implement actual tool logic in the generated `tools/<slug>.html`

## Style System

- CSS variables defined in `global.css` `:root` (`--primary`, `--bg`, `--radius`, etc.)
- Homepage category colors use per-category CSS variable classes (`.cat-encode`, `.cat-time`, etc.) set via inline `style="--cat-color:..."` on cards
- Responsive breakpoints: 768px (tablet), 640px (header wraps), 480px (mobile compact)
- Homepage layout: full-width hero + sticky category tabs + 4-col grid. No sidebar.

## SEO Stack

- JSON-LD structured data on every page (`WebApplication` for tools, `WebSite` for home, `AboutPage` for about)
- Open Graph + Twitter Card meta tags
- Baidu auto-push script on homepage
- `robots.txt` allows all, references sitemap
- `sitemap.xml` generated by script, base URL `https://tools.yzn123.cc`
